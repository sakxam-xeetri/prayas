3. Distributed 6-Node Architecture

PRAYAS divides computational tasks across 6 specialized microcontroller nodes connected via high-speed ESP-NOW and MQTT wireless protocols:

Node 01 — Motor Drivetrain

Hardware: ESP32, 2x BTS7960 43A Drivers, 4x Johnson 12V 200RPM Motors.

High-torque differential drive, smooth acceleration, and zero-radius turning.

Node 02 — Servo Joint Manipulator

Hardware: ESP32, PCA9685 PWM Driver, 7x MG995 Metal Servos.

3-DOF per arm + neck yaw/pitch gesture control for posture positioning.

Node 03 — Environmental Sensor

Hardware: Arduino Nano, MPU6050 IMU, DHT11 Sensor, 16x2 LCD.

Vehicle balance monitoring, inclination detection, and environmental logging.

Node 04 — Master Control & Display

Hardware: ESP32-WROOM-32, 3.5" SPI Color TFT Display.

System state management, ESP-NOW packet routing, live diagnostic UI.

Node 05 — AI Voice & Vision

Hardware: ESP32-S3-CAM, INMP441 Microphone, MAX98357A DAC, 10W Speaker.

Speech-to-Text, cloud LLM natural dialogue, vision snapshots & audio playback.

Node 06 — Power Distribution

Hardware: 12x 18650 Pack (3S4P), 3S 40A BMS, 5V 20A & 5V 3A Bucks.

Noise-isolated high-current power rails for heavy motor loads and logic systems.
